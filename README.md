# Probabilistic Simulation of Deep Quantum Circuits and Applications to Shor's Algorithm

This repository contains the codebase for the master's thesis: *Probabilistic Simulation of Deep Quantum Circuits and Applications to Shor's Algorithm*. 

The traditional roadblock to classical simulation of quantum circuits is the necessity of tracking complex amplitudes to preserve quantum interference, which scales exponentially. This project bypasses this bottleneck by stepping outside the standard state-vector formalism and re-casting quantum mechanics entirely within the domain of classical probability theory. 

By utilizing an Informationally Complete Positive Operator-Valued Measure (IC-POVM), quantum states are mapped to classical probability distributions over a set of measurement outcomes. The challenge of quantum simulation is thereby fundamentally redefined as a problem of high-dimensional generative modeling, solved here utilizing the self-attention mechanisms of the Transformer neural network architecture.

## Core Features

* **Dynamic Uncompiled Circuit Generation**: Moving beyond simplified lookup-table simulations, this repository dynamically generates the uncompiled logical primitives of Shor's algorithm. 
* **Vedral-Barenco-Ekert (VBE) Architecture**: The arithmetic core utilizes the Cuccaro ripple-carry adder, routing localized Majority (MAJ) and Unmajority (UMA) gates through the VBE architecture to build the product before uncomputing the workspace.
* **3-Qubit POVM Dynamics**: The Transformer's target logic was expanded to compute 3-qubit transition distributions, allowing the network to natively learn the complex multi-qubit correlations generated by Toffoli gates.
* **Variance-Stabilized Mixed Monte Carlo Evaluation**: To circumvent exploding variance spikes caused by near-zero model predictions across an exponentially large Hilbert space, a variance-stabilized Mixed Monte Carlo evaluation framework is implemented.

## Repository Structure

The codebase is divided into three main components: circuit generation, probabilistic simulation, and data visualization.

### 1. Circuit Generation
* `VBE_circuits.py`: Generates the uncompiled Qiskit circuits for modular exponentiation. You input the modulus `N`, the base `a`, and the number of control qubits to output the exact, uncompiled sequence of `X`, `CNOT`, and `TOF` gates.

### 2. Probabilistic Simulation
These scripts contain the JAX/Flax-based Transformer model and the training loops used to optimize the pseudo-stochastic state transitions gate-by-gate.

* `qft_25.py`: Simulates a 25-qubit Quantum Fourier Transform applied to a 1D cluster state. This acts as a rigorous benchmark to validate the Transformer's ability to track the dynamic redistribution of entanglement.
* `N3_a2.py`: Simulates modular exponentiation for N=3, a=2 (12 qubits, 81 gates).
* `N4_a3.py`: Simulates modular exponentiation for N=4, a=3 (17 qubits, 114 gates).
* `N8_a3.py`: Simulates modular exponentiation for N=8, a=3 (22 qubits, 207 gates).
* `shor_N15_a4.py`: Simulates the complete Shor's algorithm to factor N=15 (22-qubit, 301 gates). 

### 3. Results & Visualization
The simulation scripts output gate-by-gate classical fidelity (Fc) logs as `.txt` files. We provide plotting scripts to visualize the entanglement dynamics and algorithmic recovery during the uncomputation phases.

* `plot_qft.py`: Reads the QFT tracking data to generate the color-mapped scatter plot demonstrating robust coherence across the 25-qubit array (corresponds to Figure 5 in the thesis).
* `plots_modexp_shor.py`: Reads the tracking data for the uncompiled modular exponentiation sequences to generate fidelity trajectory plots. This highlights the "Toffoli Dip" and fidelity recovery for N=3, 4, 8, and the full N=15 Shor factorization (corresponds to Figures 6 and 7 in the thesis).

## Usage

Dependencies include `jax`, `flax`, `optax`, `qiskit`, `scipy`, `pandas`, `matplotlib`, and `orbax-checkpoint`. 

**1. Generate a new circuit sequence:**
```bash
python VBE_circuits.py
```

**2. Run a simulation (e.g., factoring N=15):**
```bash
python shor_N15_a4.py
```

Note: The simulation scripts are heavily optimized for JAX on GPUs. Memory allocation parameters are pre-configured at the top of each script to prevent OOM errors during exact matrix generation.

**3. Generate the plots:**
```bash
python plot_qft.py
python plots_modexp_shor.py
```
